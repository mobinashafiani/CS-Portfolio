# CS-210 Project One: Chada Tech Clocks

## Portfolio Reflection

For this project, I created a program that displays both a 12-hour clock and a 24-hour clock. The user can add hours, minutes, and seconds through a menu and see both clocks update at the same time. This project gave me more practice with C++ and helped me better understand how different parts of a program work together.

One thing I did well in this project was organizing the code into separate functions. Instead of putting everything in one place, I created functions for displaying the clocks and updating the time. This made the program easier to read and helped me stay organized while working on it. I also tried to keep the menu simple and easy to follow.

The most challenging part of this project was making sure the time updated correctly in every situation. When seconds reached 60, the minutes needed to increase, and when minutes reached 60, the hour needed to change as well. It took some testing and debugging to make sure everything worked correctly, but that process helped me better understand program logic and problem solving.

If I could improve this project, I would add better input validation. Right now, the program assumes the user enters valid values. Adding more checks would help prevent errors and make the program easier to use. I would also like to make the menu look better and add more features in the future.

This project helped me improve my C++ skills and gave me more experience working with functions, user input, debugging, and program design.  The skills I learned from this project will help me in future courses and programming projects.
To keep the code easy to read and maintain, I used clear function names, organized the program into smaller tasks, and kept the formatting consistent throughout the code. This made it easier to test the program, find mistakes, and make changes when needed.

  ## How can I ensure that my code, program, or software is functional and secure?
I can ensure that my code is functional and secure by testing it thoroughly and validating all input before it is processed. During this course, I learned that software should be tested under both normal and unexpected conditions to verify that it behaves correctly. Writing unit tests helped me identify issues early and confirm that the application met the required specifications. I also learned the importance of validating user input to prevent invalid data from affecting the reliability of the software. Combining testing, validation, and careful development practices helps create software that is both dependable and secure.

## How do I interpret user needs and incorporate them into a program?
I interpret user needs by carefully reviewing the project requirements and identifying the functionality that users expect. Once the requirements are clear, I translate them into classes, methods, validation rules, and test cases. In this project, requirements such as unique identifiers, field length limits, and appointment date restrictions were incorporated directly into the program design. Creating tests based on the requirements allowed me to verify that the software behaved as expected and fulfilled the needs of the user.

## How do I approach designing software?
I approach software design by first understanding the problem that needs to be solved and then breaking it into smaller, more manageable parts. This helps keep the code organized and makes it easier to maintain and test. Throughout this course, I designed separate classes for storing information and managing operations, which improved the overall structure of the program. I also try to think about readability, maintainability, and future improvements when designing software. Planning the design before implementation helps reduce errors and creates a stronger foundation for development.
